# 고양이 체포 작전 — 개발 계획

## 현재 상태 (v0.1 프로토타입)
- `index.html` 하나에 들어 있음 (Three.js 0.160)
- 거실 배치는 코드 맨 위 `LAYOUT` 데이터: 벽 4면, 창문/현관/주방 개구부, 가구 12종
- 숨는 자리 8곳: 소파 담요 속, 커피테이블 아래, TV장 칸, 책상 아래, 커튼 뒤, 책장 꼭대기, 안락의자 뒤, 택배 상자
- 도구: 맨손(확률 낮음, 실패하면 도주) / 그물(투척, 범위 판정) / 간식(고양이를 밖으로 유인)
- 사건 3개: 치즈 → 고등어 → 까망(검은 고양이, 어두운 곳에서 눈만 보임)
- 조작: 자이로 센서로 둘러보기. 센서가 없으면 드래그로 둘러보기, 두 손가락으로 확대
- 입체 음향 울음소리, 화면 밖 방향 표시, 진동
